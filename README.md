ITI_DB 🛢️ | SQL Database Project
This repository contains SQL scripts and database solutions related to ITI (Information Technology Institute) training. It includes structured queries, database design, normalization, and practical exercises covering key SQL concepts like:

✅ Database Schema Design (ERD, Normalization)
✅ DDL & DML Operations (Create, Insert, Update, Delete)
✅ Joins & Subqueries (INNER, LEFT, RIGHT, FULL)
✅ Stored Procedures & Functions
✅ Triggers & Views
✅ Indexing & Performance Optimization

📂 Project Structure:
/Schema/ → Database creation scripts (DDL)
/Queries/ → Complex SQL queries & optimizations
/Procedures/ → Stored procedures & functions
/Triggers/ → Database triggers for automation
